# LOL Quiz v3.0

리그 오브 레전드 비공식 팬 제작 챔피언 퀴즈.

## 게임 방식
- 게임 시작 전에 10/20/50/173문제 중 선택
- 초상화 / 스킬 아이콘 / 스킬 이름 / 일러스트 조각 중 복수 선택 가능
- 랜덤 출제, 한 판에서 챔피언 중복 방지, 4지선다, 즉시 정오답 표시
- 자동 저장 및 이어하기, 리셋 확인, 결과 및 오답 기록

## GitHub Pages 배포
1. GitHub에서 `lol-quiz` 저장소 생성
2. 이 폴더 안의 **파일들**을 저장소 루트에 업로드 (`index.html`이 최상위에 있어야 함)
3. Settings → Pages → Deploy from a branch → main / root → Save
4. 배포 URL `https://<사용자명>.github.io/lol-quiz/` 접속
5. iPhone Safari → 공유 → 홈 화면에 추가

## 데이터 및 오프라인 관련 유의사항
- 최초 플레이 시 인터넷 연결 필요: Riot Data Dragon 최신 버전, 챔피언 메타데이터, 이미지 다운로드
- 설정 화면의 **오프라인 데이터 준비** 버튼으로 가능한 모든 문제 데이터와 이미지를 기기에 저장. 준비 완료 후 비행기 모드에서 실제 작동을 확인할 것.
- 브라우저의 저장 공간/캐시 삭제 시 오프라인 데이터와 게임 진행 기록이 사라질 수 있음.
- 공식 패치 데이터에 173명보다 적은 챔피언이 존재하면 173문제 모드가 제한될 수 있음.
- 라이엇 공식 챔피언 이미지/스킬명은 Data Dragon에서 실시간으로 가져오므로 해당 서비스에 접근할 수 없는 환경에서는 최초 데이터 다운로드가 불가능함.
- 챔피언 일러스트 조각은 고정된 위치를 확대하여 표시하는 방식임.
- Riot Games의 공식 게임이나 후원 프로젝트가 아님.

## 개발/로컬 테스트
`python -m http.server 8000` 후 `http://localhost:8000`에서 확인. 파일을 직접 더블클릭하면 브라우저 정책상 정상 동작하지 않을 수 있음.
